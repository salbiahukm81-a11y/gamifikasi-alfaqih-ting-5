# Gamifikasi Alfaqih – Pendidikan Islam Tingkatan 5

21 game interaktif (105 misi) berdasarkan buku teks Pendidikan Islam Tingkatan 5 KSSM dan Nota al-Faqih Ting 5.

- Halaman utama: `index.html`
- Setiap pelajaran: `pN/` (P1–P21), kandungan dalam `pN/lesson.js`
- Enjin game: `assets/engine.js`, `assets/engine.css`
- 20 jenis permainan dan nota flash card bagi setiap pelajaran
- Level 1, Level 2, Level 3 · markah, bintang, lencana, sijil, papan juara, butang kongsi pautan
